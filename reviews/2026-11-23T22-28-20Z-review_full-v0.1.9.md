## Needs Attention Now

The 7 most serious of 25 high-severity problems; the others are first under Other Improvements. Tick each off as it is fixed.

- [ ] 🔴 **Implementation differs from the design: Report named by UTC time in reviews folder, never overwrite.** review_report.rs falls back to an epoch-based stamp truncated to 10 chars; save_to writes outside reviews/; create_new prevents overwrite. **Fix:** Use the current UTC time as fallback and constrain save_to.
- [ ] 🔴 **Implementation differs from the design: No logs; secrets only in memory and headers.** scripts/meridian-mcp-prod.sh instructs storing the API key in ~/.config/meridian/api-key. **Fix:** Use a keychain or record the exception.
- [ ] 🔴 **Implementation differs from the design: Runs on four platforms (smoke-tested).** smoke.py EXPECTED_TOOLS lacks meridian_move_review, which tools.rs registers, so the exact-match check fails. **Fix:** Add meridian_move_review to EXPECTED_TOOLS.
- [ ] 🔴 **A high-priority stakeholder need is not delivered: The Architecture Passphrase, API key and source text are never persisted or logged.** Only the passphrase decision answers it; the API key path to disk is unaddressed. **Fix:** Add an API key handling decision.
- [ ] 🔴 **A high-priority stakeholder need is not delivered: A long review must neither block the agent forever nor lose its result.** The 15-minute bounded poll exists, but HTTP calls lack timeouts and a transient poll error gives no rejoin hint. **Fix:** Add request timeouts and a rejoin hint on errors.
- [ ] 🔴 **A high-priority stakeholder need is not delivered: The client follows the mcp-api.md v1 wire contract exactly.** Paths, headers and codes follow v1, but there is no conformance test and path IDs are unencoded. **Fix:** Add contract tests and encode IDs.
- [ ] 🔴 **A high-priority stakeholder need is not delivered: The wire contract meridian-docs/architecture/mcp-api.md v1 is authoritative for the client.** Followed in backend.rs, but nothing verifies it against the spec. **Fix:** Test against mcp-api.md.
